# Semantic Visualization and Query Guide for MASt3R-SLAM

This guide explains how to visualize and query the semantic point clouds generated by MASt3R-SLAM.

## Overview

MASt3R-SLAM generates two types of output files:
1. **PLY files**: 3D point clouds with semantic labels
   - `{name}.ply` - Original RGB colors
   - `{name}_seg_color.ply` - Semantic segmentation colors
2. **JSON file**: `{name}_semantic_map.json` - Maps label IDs to object names

## Tools

### 1. visualize_semantic_ply.py - Interactive 3D Viewer

A real-time 3D viewer using Open3D for exploring semantic point clouds.

#### Installation
```bash
pip install open3d plyfile
```

#### Basic Usage
```bash
# View with RGB colors
python visualize_semantic_ply.py logs/hierarchical_test/my.ply

# View with semantic colors
python visualize_semantic_ply.py logs/hierarchical_test/my_seg_color.ply --semantic

# Include semantic map for better labels
python visualize_semantic_ply.py logs/hierarchical_test/my.ply \
    --semantic-map logs/hierarchical_test/my_semantic_map.json
```

#### Features
- **Toggle colors**: Press 'S' to switch between RGB and semantic colors
- **Navigation**: 
  - Left mouse: Rotate
  - Scroll: Zoom
  - Middle mouse: Pan
- **Show statistics**: Add `--stats` to see object counts
- **Filter objects**: `--filter chair table` to show only specific objects
- **Export filtered**: `--export filtered.ply --filter chair`

#### Examples
```bash
# Show object statistics
python visualize_semantic_ply.py logs/hierarchical_test/my.ply --stats

# View only furniture
python visualize_semantic_ply.py logs/hierarchical_test/my.ply --filter chair table desk

# Export all computer equipment
python visualize_semantic_ply.py logs/hierarchical_test/my.ply \
    --filter computer monitor keyboard --export computer_equipment.ply
```

### 2. query_semantic_objects.py - Query and Analysis Tool

A command-line tool for querying and extracting specific objects.

#### Basic Usage
```bash
# List all object types in the scene
python query_semantic_objects.py logs/hierarchical_test/my.ply --list

# Query specific objects
python query_semantic_objects.py logs/hierarchical_test/my.ply --query chair

# Get a specific instance
python query_semantic_objects.py logs/hierarchical_test/my.ply --instance 5

# Query by region (x, y, z, radius)
python query_semantic_objects.py logs/hierarchical_test/my.ply --region 0 0 0 2.0
```

#### Advanced Features
```bash
# Query and visualize chairs
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --query chair --visualize

# Export all tables to a new PLY file
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --query table --export tables_only.ply

# Save query results as JSON
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --query "computer" --json computer_info.json
```

## Common Use Cases

### 1. Explore the Scene
```bash
# First, see what objects are in the scene
python query_semantic_objects.py logs/hierarchical_test/my.ply --list

# Then visualize with statistics
python visualize_semantic_ply.py logs/hierarchical_test/my.ply --stats --semantic
```

### 2. Extract Specific Objects
```bash
# Extract all chairs
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --query chair --export chairs.ply

# Visualize the extracted chairs
python visualize_semantic_ply.py chairs.ply
```

### 3. Analyze Object Distribution
```bash
# Get detailed info about all computers in the scene
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --query computer --json computer_analysis.json

# Query what's near a specific point
python query_semantic_objects.py logs/hierarchical_test/my.ply \
    --region 1.5 0.8 0.0 0.5 --visualize
```

### 4. Create Filtered Visualizations
```bash
# View only non-background objects
python visualize_semantic_ply.py logs/hierarchical_test/my.ply \
    --filter -background --semantic

# Export workspace objects (desk, chair, computer)
python visualize_semantic_ply.py logs/hierarchical_test/my.ply \
    --filter desk chair computer monitor --export workspace.ply
```

## Tips

1. **Performance**: For large point clouds, filtering before visualization improves performance
2. **Colors**: The `_seg_color.ply` files already have semantic colors baked in
3. **Partial matching**: Queries support partial name matching (e.g., "comp" matches "computer")
4. **Multiple objects**: Use space-separated names to query multiple object types

## Troubleshooting

- **No semantic labels found**: Make sure you're using PLY files from MASt3R-SLAM with semantic processing enabled
- **Missing colors**: Some PLY viewers don't support custom properties. Use the provided tools or CloudCompare
- **Large files**: Use filtering to reduce point cloud size before visualization

## External Tools

For more advanced visualization:
- **CloudCompare**: Professional point cloud viewer with semantic property support
- **MeshLab**: Good for basic viewing and filtering
- **Blender**: For rendering and animation of semantic point clouds
