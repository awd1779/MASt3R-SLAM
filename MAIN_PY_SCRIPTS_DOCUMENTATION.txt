1. mast3r_slam/tracker.py
================================================================================
PURPOSE: 
Tracks camera motion between frames and manages semantic label propagation across the 3D reconstruction.

CLASS: FrameTracker
- Initialized with: model, keyframes, device, initial_global_id_to_class_label_map, semantic_processor
- Maintains global semantic label mapping across all frames
- Manages global_instance_ids assignment and propagation

KEY METHODS:
- track(frame: Frame) -> (new_kf, match_info, try_reloc)
  - Performs frame-to-keyframe matching using MASt3R
  - Updates frame's pointmap (X_canon, C)
  - Processes semantics for ALL frames (ensures semantic data available when frame becomes keyframe)
  - Maps 2D semantic masks to 3D points
  - Propagates/merges labels from previous keyframes
  - Applies aggressive semantic propagation when >40% points unlabeled
  - Determines if frame should become new keyframe
  - Returns: (bool for new keyframe, match metrics, bool for relocalization needed)

OUTPUTS:
- Updates frame.global_instance_ids (Nx1 tensor of semantic labels per 3D point)
- Updates g_global_id_to_class_label_map (dict mapping global IDs to class names)
- Manages label confidence scores for refinement
- Provides tracking metrics for keyframe selection

SEMANTIC PROPAGATION STRATEGY:
1. Initial assignment: Maps 2D mask labels to 3D points
2. Keyframe merging: Merges labels with same class from previous keyframes
3. Aggressive propagation (if >40% unlabeled):
   - Spatial propagation within 10cm radius
   - Nearest-neighbor filling within 20cm
   - Achieves typically >60% label coverage

2. mast3r_slam/semantic_processor_v2.py
================================================================================
PURPOSE:
Enhanced semantic processor integrating SAM segmentation with CLIP classification,
including optimizations for batch processing, caching, and multi-model ensemble.

CLASS: SemanticProcessorV2
- Configurable features: batch_processing, caching, post_processing, ensemble
- Integrates multiple optimization modules

KEY METHODS:
- initialize_models()
  - Loads SAM (segment anything) model
  - Loads CLIP model(s) 
  - Prepares text embeddings from prompts

- process_frame(frame_data, mode='full', use_cache=True)
  - mode='full': Complete SAM+CLIP processing
  - mode='fast': Cached or simplified processing
  - Checks viewpoint cache for similar poses
  - Returns complete semantic results

- _perform_segmentation(image_tensor) -> List[Dict]
  - Runs SAM to generate instance masks
  - Sorts masks by area (largest first)
  - Returns mask dictionaries with segmentation data

- _batch_classification(image_tensor, sam_masks, frame_id) -> Dict
  - Batches multiple mask crops for efficient CLIP inference
  - Optionally uses ensemble of CLIP models
  - Returns predictions, confidences, metadata

OUTPUTS:
- local_instance_mask: (H,W) tensor with instance IDs
- local_id_to_class_map: Dict[int, str] mapping local IDs to class names
- classification_results: Detailed confidence scores
- sam_masks: Raw SAM segmentation masks
- processing_time: Performance metrics
- frame_id: Frame identifier

PERFORMANCE FEATURES:
- Batch processing: Groups multiple crops for single CLIP forward pass
- Feature caching: Stores and reuses CLIP features
- Viewpoint caching: Reuses semantics from similar camera poses
- Post-processing: Temporal consistency across frames

3. mast3r_slam/semantic_mapper.py
================================================================================
PURPOSE:
Handles the critical mapping between 2D semantic masks and 3D MASt3R points,
with proper alignment handling and spatial refinement.

CLASS: SemanticMapper

KEY METHODS:
- get_pixel_coordinates_for_points(frame_shape, num_points, downsample=1)
  - Determines pixel coordinates for each 3D point
  - Handles MASt3R's row-major point ordering
  - Adapts to different point densities (subsampled/full)
  - Returns: (num_points, 2) tensor of (y,x) coordinates

- map_2d_labels_to_3d_points(semantic_mask, confidence_map, num_points, frame_shape, confidence_threshold)
  - Core function mapping 2D mask to 3D points
  - Uses bilinear interpolation for sub-pixel accuracy
  - Applies confidence filtering
  - Returns: (labels, valid_mask) tensors

- refine_labels_with_3d_proximity(points_3d, labels, label_confidences, distance_threshold, min_neighbors)
  - Refines labels using 3D spatial coherence
  - Propagates high-confidence labels to nearby points
  - Removes isolated label assignments
  - Returns: Refined label tensor

- propagate_high_confidence_labels(points_3d, labels, confidences, propagation_radius, confidence_threshold)
  - Aggressive label propagation for unlabeled points
  - Uses KNN search within radius
  - Weighted by confidence scores
  - Returns: Updated labels with propagation

TECHNICAL DETAILS:
- Handles MASt3R point structure (typically one point per pixel)
- Robust to varying point densities
- Sub-pixel interpolation for accurate label assignment
- Confidence-based filtering and propagation

4. mast3r_slam/evaluate.py
================================================================================
PURPOSE:
Saves all outputs from the SLAM system including trajectory, 3D reconstruction,
and semantic segmentation results.

KEY FUNCTIONS:
- prepare_savedir(args, dataset)
  - Creates output directory structure
  - Returns: (save_dir, sequence_name)

- save_traj(logdir, logfile, timestamps, frames, intrinsics)
  - Saves camera trajectory in TUM format
  - Includes timestamps and pose matrices
  - Output: .txt trajectory file

- save_reconstruction(savedir, filename, frames, C_threshold, global_id_to_name_map)
  - Main reconstruction saving function
  - Aggregates points from all keyframes
  - Filters by confidence threshold
  - Creates multiple outputs:
    1. Base .ply with RGB colors
    2. _seg_color.ply with semantic colors
    3. Post-processes labels for consistency
  - Handles label color assignment

- generate_distinct_colors(n_colors, seed=42)
  - Creates visually distinct colors for semantic labels
  - Uses HSV color space for better distribution
  - Adaptive strategy based on number of labels
  - No hardcoded object-specific colors

- save_ply(filename, points, colors, labels, label_map, property_name)
  - Low-level PLY file writing
  - Includes semantic labels as vertex property
  - Adds label map as PLY comments
  - Supports both RGB and semantic coloring

OUTPUTS:
1. trajectory.txt - Camera poses with timestamps
2. reconstruction.ply - 3D points with RGB colors
3. reconstruction_seg_color.ply - 3D points with semantic colors
4. reconstruction_semantic_map.json - Label ID to class name mapping
5. keyframes/ - Individual keyframe data (optional)

POST-PROCESSING:
- Removes small isolated clusters (min_cluster_size=50)
- Merges similar labels within spatial proximity
- Improves semantic consistency

================================================================================
EXECUTION FLOW IN MAIN.PY
================================================================================

1. INITIALIZATION:
   - Load MASt3R model and dataset
   - Create SemanticProcessorV2 with optimizations
   - Create SemanticMapper for 3D alignment
   - Initialize FrameTracker with semantic processor
   - Start backend process for global optimization

2. FIRST FRAME (INIT MODE):
   - Run MASt3R mono inference
   - Process full semantics with SemanticProcessorV2
   - Map 2D masks to 3D points with SemanticMapper
   - Initialize global_instance_ids
   - Add as first keyframe

3. TRACKING MODE (SUBSEQUENT FRAMES):
   - FrameTracker.track() processes each frame:
     a. Match with last keyframe
     b. Update 3D points
     c. Process semantics (fast mode with caching)
     d. Propagate labels from keyframes
     e. Apply aggressive propagation if needed
     f. Decide if new keyframe needed

4. NEW KEYFRAME:
   - Full semantic processing if not already done
   - Add to keyframe list
   - Queue for global optimization

5. FINAL OUTPUT:
   - Save trajectory
   - Save reconstruction with semantic colors
   - Save semantic map JSON
   - Apply post-processing for consistency

PERFORMANCE OPTIMIZATIONS

1. Semantic Processing:
   - Batch CLIP inference (32 crops/batch)
   - Feature caching (1000 item LRU cache)
   - Viewpoint caching (reuse similar poses)
   - Fast mode for non-keyframes

2. Label Propagation:
   - Spatial KNN search with radius limits
   - Chunk processing for memory efficiency
   - Confidence-based filtering
   - Aggressive propagation only when needed

3. Multi-processing:
   - Backend process for global optimization
   - Visualization process (optional)
   - Shared memory for keyframe data
